описание игры -R_o_t_s-: (RU)

Цель игрока — нажимать на плиты в нужный момент. В зависимости от точности нажатия ему начисляются очки. В конце уровня очки подсчитываются, и игрок получает оценку от 1 до 4 в зависимости от набранного количества очков. Помимо уже доступных песен, игрок сможет добавлять свои. В будущем появятся различные "модификаторы", например «ядовитые плиты», которые будут постепенно отнимать очки.

этапы разработки:
1) "Ядро"
   построение базовых функций игры: отслеживание времени, определения нажатия клавиш, интеграция "демо сцены", отладка предыдущих этапов.
2) "музыка"
   интеграция музыки в игру, настройка кода для вывода плиток, отладка предыдущих этапов.
3) "доп функции"
   интеграция в игру "модификаторов" для усложнения геймплея (по желанию игрока их можно включить), добавление возможности менять сцены игры, добавление настроек, интеграция системы "счета".
4) "отклик"
   добавление функции "отклика окружения" - возможность игры реагировать на музыку или нажатия плиток.

   Game description -R_o_t_s-: (EN)

The player’s goal is to press the tiles at the right moment. Points are awarded depending on the accuracy of the press. At the end of the level, the points are tallied, and the player receives a score from 1 to 4, depending on the number of points accumulated. In addition to the songs already available, the player will be able to add their own. In the future, various "modifiers" will appear, for example, “poisoned tiles,” which will gradually deduct points.

Development stages: 
1) “Core”
 building the game’s basic functions: time tracking, detecting key presses, integrating the “demo scene,” debugging previous stages.
2) “Music”
 integrating music into the game, configuring the code for displaying tiles, debugging previous stages.
3) “Additional functions”
 integrating “modifiers” into the game to make the gameplay more challenging (they can be enabled at the player’s discretion), adding the ability to change game scenes, adding settings, integrating the “score” system.
4) “response”
Adding the “environmental response” function — the game’s ability to react to music or button presses.

游戏介绍-R_o_t_s-:(ZH)

玩家的目标是在正确的时刻点击瓷砖。 根据点击的准确性，点被授予他。 在水平结束时，点数被计算，玩家获得从1到4的分数，这取决于得分的数量。 除了已经可用的歌曲，播放器将能够添加自己的。 未来会出现各种"修饰符"，比如"毒盘"，会逐渐带走积分。

发展阶段:

"核心"是游戏基本功能的构建：时间跟踪，击键检测，"演示场景"的集成，以前阶段的调试。

"音乐"音乐集成到游戏中，设置显示瓷砖的代码，调试以前的阶段。

"附加功能"将"修改器"集成到游戏中，使游戏玩法复杂化（它们可以根据玩家的要求打开），增加更改游戏场景的能力，添加设置，集成"帐户"系统。

"响应"添加"环境响应"功能-游戏响应音乐或瓷砖点击的能力。

Description du jeu: - R_o_t_s -: (FR)

Le but du joueur est de cliquer sur les plaques au bon moment. En fonction de la précision de la pression, il reçoit des points. À la fin du niveau, les points sont comptés et le joueur obtient un score de 1 à 4 en fonction du nombre de points marqués. En plus des chansons déjà disponibles, le joueur pourra ajouter ses propres chansons. À l'avenir, il y aura différents "modificateurs", tels que les «plaques toxiques», qui enlèveront progressivement les points.

"musique" l'intégration de la musique dans le jeu, la configuration du code pour la sortie des tuiles, le débogage des étapes précédentes.

"fonctions supplémentaires" intégration dans le jeu " modificateurs "pour compliquer le gameplay (si le joueur peut les activer), l'ajout de la possibilité de changer les scènes du jeu, l'ajout de paramètres, l'intégration du système"compte".
